# OBJ Simple Reader

Este programa en Rust lee un archivo `.obj` y muestra en consola los **primeros 5**  
vértices (`v`), normales (`vn`) y coordenadas de textura (`vt`).

## Ejecución

Desde la raíz del proyecto, compila y ejecuta usando **cargo**:

```bash
cargo run -- "assets/AnyConv.com__Wizardus Maximus.obj"
